# 🚌 Bus Reservation System in C

## 📖 Overview
The **Bus Reservation System** is a console-based project developed in the **C programming language** that automates the process of managing bus information, passenger bookings, and ticket cancellations.  
It provides a **menu-driven interface** that allows users to add new buses, reserve seats, cancel bookings, and display passenger details — all while storing and retrieving data using **file handling** in C.

This project demonstrates essential programming concepts like **structures**, **functions**, and **file input/output**, making it an excellent learning project for beginners, especially **BCA and B.Tech students**.

---

## 🎯 Objectives
- To understand and implement **File Handling** in C.
- To demonstrate the use of **Structures** for managing data.
- To create a **Menu-Driven Program** that simulates a real-world reservation system.
- To build a **mini project** that enhances logical thinking and programming skills.

---

## ⚙️ Features
✅ Add new bus details (bus number, destination, seats, and price)  
✅ View all available buses  
✅ Book tickets for passengers  
✅ Cancel existing reservations  
✅ Display passenger and seat details  
✅ Data stored permanently using **text files**

## 🪜 How It Works
1. **Add Bus:** Admin can input new bus details and store them in a file.  
2. **View Buses:** Displays all available buses with destination, seats, and price.  
3. **Reserve Seats:** Allows users to select a bus and book seats.  
4. **Cancel Booking:** Removes a reservation and updates seat availability.  
5. **Display Records:** Shows all passenger and bus data.

---

## 🧩 File Handling Details
All bus data and passenger information are stored in `Bus.txt`.  
Each record includes:Bus Number, Destination, Seats, Price

This ensures that data is persistent across multiple program executions.
